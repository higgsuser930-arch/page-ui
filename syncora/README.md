# SYNCORA — достарыңмен бірге фильм көр

Онлайн «бірге көру» платформасы: 2–28 адам бір бөлмеге жиналып, админ қосқан фильмді **бір секундта** көреді, көріп отырып чатта талқылайды. Достар тізімі, жеке хат, @username, екі тіл (қазақша / English), тек Google арқылы тіркелу.

**Технологиялар:** React + Vite + TypeScript, Firebase (Authentication, Firestore, Hosting). Жеке сервер керек емес: Firebase-тің тегін «Spark» жоспары басында жеткілікті.

## Мүмкіндіктер

| | |
|---|---|
| **Кіру** | Тек Google аккаунты. Жаңа аккаунтқа сайт өзі кездейсоқ бос `@username` береді (мыс. `tulpar_kino4821`), кейін «Баптаулар» бетінде өзгертуге болады (бірегейлігі тексеріледі). |
| **Бөлмелер** | 2–28 орын, жабық (тек сілтеме арқылы) немесе ашық (тізімде көрінеді). Иесі админдер тағайындай алады, қатысушыны шығара алады, бөлмені жоя алады. |
| **Видео** | YouTube, Vimeo, тікелей `.mp4/.webm/.mov` және `.m3u8` (HLS) сілтемелері — **дәл синхрон**. «Әркім өз файлын таңдайды» режимі — фильм файлы әр қатысушыда болса, ол да синхрондалады. Басқа сайттар (Rutube, Dailymotion, Google Drive, Twitch, т.б.) iframe арқылы ашылады, бірақ оларды синхрондау мүмкін емес. |
| **Синхрон** | Ойнатуды админ басқарады: тоқтатса, айналдырса — бәрінде бірдей. Құрылғылардың сағаты сервермен салыстырылып түзетіледі. Кеш кірген адам фильмнің дәл сол сәтіне қосылады. Браузер автоойнатуды бұғаттаса — «Көруге қосылу» батырмасы шығады. |
| **Чат** | Бөлме чаты + жылдам реакциялар (😂🔥👏…), кім онлайн екені көрінеді. |
| **Достар** | `@username` бойынша іздеу, сұрау жіберу/қабылдау, достан шығару. Жеке хат тек достар арасында. Бөлмеге досты бір батырмамен шақыру (жеке хатқа шақыру картасы келеді). |
| **Жазылым** | Сайтқа кіру ақылы: **айына 999 ₸**, жаңа қолданушыға **алғашқы ай 499 ₸ (−50%)**. Карта арқылы CloudPayments, ай сайын автоматты жаңарады, «Баптаулар» бетінен тоқтатуға болады. Төлемді тек сервер растайды. |
| **Дизайн** | Қара + күлгін + ақ, телефонға бейімделген. |

## 1. Firebase жобасын ашу (бір рет, ~10 минут)

1. https://console.firebase.google.com → **Add project** → атауы, мысалы `syncora`.
2. **Build → Authentication → Get started → Sign-in method → Google → Enable** → қолдау көрсету email-ін таңда → Save.
3. **Build → Firestore Database → Create database** → *Production mode* → орналасқан жері: `europe-west` (Қазақстанға жақын).
4. **Project settings (⚙) → Your apps → Web (`</>`)** → қосымша атауы `syncora` → **Register**. Көрсетілген `firebaseConfig` мәндерін көшір.
5. Осы папкада `.env.example` файлын `.env` деп көшіріп, мәндерді толтыр:
   ```
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=syncora-xxxx.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=syncora-xxxx
   ...
   ```
6. `.firebaserc.example` файлын `.firebaserc` деп көшіріп, ішіне project ID жаз.

## 2. Компьютерде іске қосу

Node.js 20+ керек.

```bash
cd syncora
npm install
npm run dev          # http://localhost:5173
```

## 3. Интернетке шығару

```bash
npx firebase login
npm run deploy       # build + Firestore ережелері + Hosting
```

Сайт `https://<project-id>.web.app` мекенжайында ашылады.

## 4. Жеке доменді қосу (мысалы `syncora.kz`)

1. **Домен сатып ал.** `.kz` домені Қазақстан тіркеушілері арқылы алынады (мысалы ps.kz, hoster.kz). `.com`/`.app` — Cloudflare, Namecheap, Porkbun.
2. Firebase Console → **Hosting → Add custom domain** → `syncora.kz` (және `www.syncora.kz` → `syncora.kz`-ке бағыттау).
3. Firebase көрсеткен **A** және **TXT** жазбаларын домен тіркеушісінің DNS панеліне қос. Тексеру бірнеше минуттан 24 сағатқа дейін созылады, SSL (https) сертификатын Firebase өзі береді.
4. **Маңызды:** Authentication → **Settings → Authorized domains** → `syncora.kz` және `www.syncora.kz` қос. Әйтпесе Google арқылы кіру жұмыс істемейді.
5. (Ұсыныс) Google кіру терезесінде `firebaseapp.com` емес, өз доменің көрінуі үшін `.env` ішінде `VITE_FIREBASE_AUTH_DOMAIN=syncora.kz` қойып, қайта `npm run deploy` жаса.

## 5. Жазылымды (төлем қабылдауды) іске қосу

Төлем **CloudPayments** арқылы қабылданады: ол Қазақстанда теңгемен жұмыс істейді және ай сайынғы автоматты төлемді қолдайды.

1. **ЖК (ИП) немесе ЖШС (ТОО) ашыңыз.** Төлем провайдері тек заңды тұлғамен немесе ЖК-мен шарт жасайды.
2. **Firebase-ті Blaze жоспарына ауыстырыңыз.** Cloud Functions тек сол жоспарда жұмыс істейді. Тегін көлем сақталады. Бюджет ескертуін қойыңыз.
3. **`.env` файлындағы сатушы деректерін толтырыңыз:** `VITE_LEGAL_NAME`, `VITE_LEGAL_BIN`, `VITE_LEGAL_ADDRESS`, `VITE_SUPPORT_EMAIL`, `VITE_SUPPORT_PHONE`. Олар оферта, құпиялық және қайтару беттерінде шығады. Провайдер сайтты тексергенде осы беттерді қарайды.
   - Құжат мәтіндері — үлгі. Қолданар алдында заңгерге көрсетіңіз. Қажет болса орыс тіліндегі нұсқасын да қосыңыз.
4. **cloudpayments.kz сайтында тіркеліңіз.** Тіркелген соң `Public ID` және `API Secret` аласыз.
   - `.env` → `VITE_CP_PUBLIC_ID=<Public ID>`
   - `npx firebase functions:secrets:set CP_API_SECRET` → API Secret-ті енгізіңіз.
   - `functions/.env.<project-id>` → `CP_PUBLIC_ID=<Public ID>`
   - Виджет пен API мекенжайларын провайдерден нақтылаңыз. Қажет болса `VITE_CP_WIDGET_URL` және `CP_API_URL` мәндерін өзгертіңіз.
5. `npm run deploy` жасаңыз.
6. **CloudPayments кабинетінде хабарламаларды (уведомления) қосыңыз:**
   - Check → `https://europe-west1-<project-id>.cloudfunctions.net/cpCheck`
   - Pay → `.../cpPay`, Fail → `.../cpFail`, Recurrent → `.../cpRecurrent`

**Бағаны өзгерту немесе төлемді уақытша өшіру.** Қайта шығарудың керегі жоқ: Firebase Console → Firestore → `config/app` құжатын жасап, мына өрістерді қойыңыз:

| Өріс | Мағынасы |
|---|---|
| `priceKzt` | негізгі баға (999) |
| `introPriceKzt` | алғашқы ай (499) |
| `subscriptionRequired` | `false` болса, сайт бәріне тегін ашылады (мысалы, провайдер әлі мақұлдамаған кезде) |

**Өзіңізге немесе тестерлерге тегін кіру** беру үшін `subscriptions/<uid>` құжатын қолмен жасаңыз: `activeUntil` = алыс күн (timestamp).

## 6. Тестілеу (Firebase жобасыз, локалды эмуляторлармен)

Java 11+ керек.

```bash
npm run emulators                 # 1-терминал: Auth + Firestore + Functions эмуляторлары
#   (алдымен: functions/.secret.local → CP_API_SECRET=test_secret_for_emulator,
#    functions/.env.local → CP_PUBLIC_ID=test_pk  CP_API_URL=http://127.0.0.1:9999)
npm run dev:emulators             # 2-терминал: сайт эмуляторларға қосылады
npm run test:rules                # қауіпсіздік ережелерін тексеру
# e2e (Playwright + ffmpeg): тест-видео жасап, екі «қолданушымен» синхронды тексереді
ffmpeg -f lavfi -i testsrc=size=640x360:rate=25 -f lavfi -i sine=frequency=440 -t 120 -c:v libvpx -c:a libvorbis public/test.webm
npm run test:e2e
```

## Қауіпсіздік (Firestore ережелері — `firestore.rules`)

- Профильді тек иесі өзгертеді; `@username` бірегейлігі транзакциямен және ережемен кепілденеді.
- Бөлме чатын тек қатысушылар оқиды/жазады, басқаның атынан жазу мүмкін емес.
- Жазылымды тек сервер (Cloud Functions) жазады; клиент өзіне жазылым бере алмайды, бағаны өзгерте алмайды. Төлем хабарламалары HMAC қолтаңбасымен тексеріледі, қайталанған хабарлама екі рет есептелмейді, −50% жеңілдік бір аккаунтқа бір рет.
- Төлемсіз қолданушы бөлме аша/кіре алмайды, чатқа, достарға, жеке хатқа жаза алмайды — бұл UI-да ғана емес, серверде тексеріледі.
- Видео мен ойнатуды тек админ басқарады; қарапайым қатысушы тек өзін қоса/шығара алады; орын саны (≤28) серверде тексеріледі.
- Жеке хатты тек екі дос оқиды/жазады; дос сұрауын тек алушы қабылдайды.
- Email мекенжайлары базада сақталмайды.

## Шектеулер

- **Netflix, Kinopoisk, Okko сияқты ақылы/DRM сервистерді** ешбір watch-party сайты ендіре алмайды (олар мұны техникалық тұрғыда бұғаттайды). Мұндай фильмдер үшін «әркім өз файлын таңдайды» режимін немесе браузер кеңейтпесін (төмендегі ұсыныстар) қолдану керек.
- Көп сайттар iframe-ге ендіруге тыйым салады (`X-Frame-Options`) — ондай сілтеме бос терезе болып ашылады.
