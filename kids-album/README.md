# Дыбыс сиқыры — логопедиялық интерактивті альбом

Қазақ тіліндегі 37 дыбыс × 7 ойын (259) + 3 тыныс алу + 5 артикуляциялық жаттығу. Таза HTML/CSS/JS, құрастыру (build) керек емес.

## Іске қосу
Камера мен микрофон тек **HTTPS** немесе `localhost` арқылы жұмыс істейді:

    cd kids-album && python3 -m http.server 8000   # -> http://localhost:8000

Сөзді тану (`SpeechRecognition`, kk-KZ) үшін **Chrome / Edge** ұсынылады. Басқа браузерде сөйлеуді логопед «👩‍⚕️ Дұрыс айтты» батырмасымен растайды.

## Камера мен микрофон қайда
- 🌬️ Тыныс алу: микрофон үрлеуді сезеді (көбелек, шам, қайық).
- 😁 Артикуляция: камера — «айна» (бейне сақталмайды, ешқайда жіберілмейді).
- 2-ойын «Дыбысты айт»: камера-айна + микрофон (дауыс естілсе өтеді).
- 3, 4, 6, 7-ойындар: микрофон; айтқан сөз/сөйлем тексеріліп, дұрыс болса келесі тапсырмаға өтеді.
- 1 және 5-ойындар: басу арқылы автоматты тексеріледі.

## Файлдар
- `data/album-data.js` — құжаттан алынған 37 дыбыстың мазмұны (`tools/parse_docx.py` жасайды).
- `data/emoji.js` — сөз → сурет. Дәлірек сурет қажет болса осында өзгертіңіз.
- `audio/` — ElevenLabs (v3, kk) арқылы жасалған 588 аудио (`tools/gen_audio.py`). Файл ауыстыру үшін аты — мәтіннің sha1-інің алғашқы 10 символы (`manifest.js`).
- `js/app.js` — бүкіл логика.

## Ескерту
Жеке дыбыс ([ш], [а]…) сөзге айналмайтындықтан, 2-ойында тек дауыс естілгені тексеріледі, дұрыс айтылуын логопед бағалайды («Логопед режимі» 👩‍⚕️). Бағдарлама диагноз қоймайды.
