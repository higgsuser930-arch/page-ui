# Фотосуреттер

Бұл бумадағы фотолар жасанды интеллектпен (Higgsfield) жасалған; оларда нақты адамдар бейнеленбеген.

Фотоны ауыстыру үшін сол атаумен жаңа файл салыңыз. Файл жоқ болса, орнында анимацияланған градиент көрсетіледі.

| --- | --- |
| `hero.jpg` | Басты беттің бірінші экраны |
| `stage-1.jpg` … `stage-4.jpg` | Төрт кезең блоктары |
| `band.jpg` | Беттің соңындағы кең жолақ |
