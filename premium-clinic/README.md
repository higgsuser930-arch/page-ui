# Premium Clinic — логопедиялық ойын сайты

Р · Л · Й · У · М · Н · Ң дыбыстарына арналған, әр дыбыс бойынша 4 кезең (12 ойын бөлімі) бар статикалық сайт.
Құрастыру қадамы жоқ — таза HTML / CSS / JS.

## Іске қосу

```bash
cd premium-clinic
python3 -m http.server 8080   # сосын http://localhost:8080
```

`index.html` файлын тікелей браузерде ашуға да болады.

## Құрылымы

- `index.html` — кіру нүктесі
- `css/styles.css` — дизайн және анимациялар
- `js/data.js` — барлық мазмұн (сөздер, буындар, сөйлемдер, жаттығулар)
- `js/app.js` — беттер, маршруттар және ойын логикасы
- `js/audio.js` — сөз → дауыс файлы сәйкестігі
- `audio/` — 102 сөздің дауыстық жазбасы (жасанды дауыс; өз жазбаңызбен ауыстыруға болады)
- `images/` — фотосуреттер (қараңыз: `images/README.md`)

Прогресс браузердің `localStorage` жадында сақталады. Дыбыс бетіндегі
«Барлық ойынды ашу» белгісі ретпен ашылу шектеуін алып тастайды.
