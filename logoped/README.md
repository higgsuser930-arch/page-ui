# Сөйле — логопедиялық ойындар (3D Clay дизайн)

Таза HTML/CSS/JS, құрастыру қажет емес.

## Іске қосу
```
cd logoped && python3 -m http.server 8765   # содан соң http://localhost:8765
```
Камера мен микрофон тек **HTTPS** немесе **localhost** арқылы жұмыс істейді.

## Мүмкіндіктер
- 1-бөлім: микрофон дем шығаруды естиді (немесе «Басып тұрып үрле» батырмасы) — гүл ашылады, қауырсын мен қайық жылжиды.
- 2-бөлім: алдыңғы камера айна ретінде қосылады, жаттығу таймер және санауышпен жүреді.
- 3–6-бөлім: ойындар, әрқайсысында 3 деңгей. 🎤 басылғанда дауыс танылып, дұрыс/қате анықталады (қазақша, `kk-KZ`).
- Барлық түсіндірмелер дауыспен оқылады (браузердің TTS), жұлдыздар мен белгілер localStorage-та сақталады.

## Талаптар
Дауыс тану үшін Chrome / Edge (Android Chrome да болады). Safari/Firefox-та дауыс тану жоқ — сонда ересек адам «Дұрыс/Қате» батырмасымен бағалайды.
